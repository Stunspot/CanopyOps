# CanopyOps public-remediation verification

This directory binds the August 11, 2026 documentation and presentation remediation to its local checks and eventual live-publication evidence.

The governed documentation fingerprint is recorded in `verification-summary.json`, `documentation-review.json`, `documentation-accessibility-review.json`, and `visual-asset-review.json`. Customer documentation, Pages HTML/CSS, or governed visual changes invalidate those receipts and require all three reviews again.

`final-review.md` is added only after a fresh adversarial reviewer examines the coherent local commit. Live-publication evidence is added only after GitHub main and Pages serve exact final bytes and all customer routes have been exercised.
