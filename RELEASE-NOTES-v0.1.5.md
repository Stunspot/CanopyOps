# CanopyOps v0.1.5 Release Notes

Release date: **July 20, 2026**

> **Historical record:** This page describes the v0.1.5 repository-native identity and custody release. The repository now also contains a separate portable v0.1.6 package around the same operating kernel. Read [`RELEASE-STATUS.md`](RELEASE-STATUS.md) before choosing an artifact.

CanopyOps v0.1.5 is the plugin-identity and archive-custody release. It preserves the v0.1.4 operating kernel while replacing the generic greenhouse mark with a category-native cultivation-canopy operations grid and making every supported v0.1.5 distribution independently obtainable and auditable.

## Changed

- Introduced a product-specific, small-size-legible CanopyOps icon: four cultivated canopies joined by an operations grid and one coral decision point.
- Version-bound the plugin listing to the new icon rather than a mutable generic alias.
- Added canonical archives for the complete Augment, Codex plugin, and standalone CanopyOps skill.
- Added a custody ledger with source-tree and archive SHA-256 values, sizes, member counts, and extraction-parity evidence.
- Documented the distinction among canonical release assets, GitHub release assets, Claude.ai upload package, and latest-only convenience backups.
- Added a deterministic OpenAI skills-only submission ZIP and its separate custody record without weakening the full installable plugin manifest.
- Created and populated the OpenAI plugin draft; the skill passed automated scanning, while owner policy attestations and review submission remained pending at the evidence cutoff.

## Boundary

The operating skill was unchanged, so prior reviewed behavioral evidence was inherited rather than rerun.

Package validation, archive parity, listing-asset inspection, portal draft creation, and documentation review did not establish:

- cultivation-field fitness or production reliability;
- jurisdictional currency or legal correctness;
- live Claude behavior;
- OpenAI review approval, publication, or discoverability;
- accessibility conformance;
- customer outcomes.

Later Pages and documentation work are outside this release note’s evidence cutoff. See [`DOCUMENTATION-STATUS.md`](DOCUMENTATION-STATUS.md).
