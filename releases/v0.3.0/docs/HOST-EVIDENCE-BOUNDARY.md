# CanopyOps: what the evidence establishes

The portable verifier establishes archive safety, manifest relationships and byte identity between the Codex skill payload and nested Claude ZIP. Its report does not establish installation or crop behavior.

Local workspace checks exercise representative native records and browser interactions. They do not establish a sensor connection, environmental diagnosis, regulatory permission, field performance or production reliability. The UI intentionally distinguishes recorded evidence, unavailable data, illustrative material and authorizations retained in source records.

A copied installation is a file state. Host discovery, explicit invocation and tool health require separate observations. Windows/browser behavior has local evidence; macOS launches, fresh customer hosts and live Claude upload/activation are not inferred from equivalent package bytes.

Shelf currency means the current complete customer bundle matches the accepted artifact. Public repository visibility, a release upload, Discord deployment and directory approval each require their own evidence. No public announcement or directory submission is part of this interface update.
