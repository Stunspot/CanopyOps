# CanopyOps

Turn supplied crop evidence into a clear view of the room and a defensible next step. The v0.3.0 portable bundle combines the CanopyOps cultivation skill with a local visual crop workspace.

## Start here

Follow the [quick start](QUICK-START.md), then choose [Codex](INSTALL-CODEX.md) or [Claude](INSTALL-CLAUDE.md) installation. You can also open the workspace directly with Python 3.10+ using the Windows or macOS launcher under `codex/canopyops/skills/canopyops/workspace/`.

The workspace puts native observations in room, zone and time context. Compare compatible measurements, inspect two observations, capture evidence and read room plans, incidents and handoffs. Read [the workspace guide](../codex/canopyops/skills/canopyops/workspace/WORKSPACE-GUIDE.md) for the working path.

## Understand the package

[Capabilities](CAPABILITIES.md), [limitations](LIMITATIONS.md), [support](SUPPORT.md), [validation](VALIDATION.md), [package reference](PACKAGE-REFERENCE.md), [description custody](DESCRIPTION-CUSTODY.md), [provenance](PROVENANCE.md), [host evidence](HOST-EVIDENCE-BOUNDARY.md) and [maintenance](MAINTAINER-GUIDE.md) describe the usable scope and evidence.

The package verifies its own bytes. Installation, fresh-host discovery, live invocation and crop outcomes require their own observations. The workspace does not operate equipment or connect sensors.
