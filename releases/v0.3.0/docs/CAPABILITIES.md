# CanopyOps: what you can do

The cultivation skill supports crop planning and room design; crop, pest, disease and environmental investigation; environment and root-zone calculations; harvest and quality preparation; and operational/compliance handoff. Governing SOPs, approved labels, current jurisdiction sources and accountable humans constrain consequential recommendations.

The local workspace adds a persistent evidence environment. Explore observations by room and named zone, restrict the view through a chosen date, plot compatible discrete measurements and compare two observations with their provenance. Capture observations and photo references, read room/batch/incident/handoff Markdown, edit original text, import native records, export drafts and print the visible record.

Understory, Lampblack and Clearspan support different reading and inspection moods while using the same data. Original imports, prior-save history and read-hash checks support deliberate reconciliation with an agent or another writer.

See [limitations](LIMITATIONS.md) before treating any display or recommendation as operational authority.
