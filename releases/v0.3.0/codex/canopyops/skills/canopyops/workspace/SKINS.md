# Three environments for reading the crop

One evidence model, three working environments. Switching changes presentation and hierarchy while preserving room/date/zone scope, comparison choices, drafts, source values and authority. Older Sodium preferences open Lampblack; older Sunprint preferences open Clearspan. Understory remains available.

## Shared truth, adapted bodies

These are interface environments, not environmental readings. The room/zone positions are schematic. A reported concern is labeled and shaped as well as colored; an unrecorded location never reads as healthy. Charts retain separate, discrete supplied points and exact-value controls. At narrow widths the composition becomes one reading column and the zone bays stack; source comparison and capture reflow. Keyboard focus and reduced motion remain supported. System fonts are used locally without remote requests or bundled commercial type.
