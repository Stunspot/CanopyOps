# CanopyOps Pages Source

This directory is the source for the CanopyOps GitHub Pages site.

- `index.html` contains the semantic page structure and project copy.
- `style.css` contains the responsive visual presentation.
- `assets/canopyops-hero.png` is a generated 1600×900 raster image used by the site and public README.
- `.nojekyll` instructs GitHub Pages to serve the directory directly.

## Content authority

The site summarizes the living repository documentation. It does not independently define package versions, platform availability, safety authority, or verification status.

Use these root documents as the canonical sources:

- [`../RELEASE-STATUS.md`](../RELEASE-STATUS.md) — distribution and publication state;
- [`../README.md`](../README.md) — product orientation;
- [`../INSTALL.md`](../INSTALL.md) — installation and recovery;
- [`../SAFETY-AND-SCOPE.md`](../SAFETY-AND-SCOPE.md) — operational boundary;
- [`../DOCUMENTATION-STATUS.md`](../DOCUMENTATION-STATUS.md) — documentation scope and review custody.

## Technical boundary

The site uses no JavaScript, tracking code, analytics, remote fonts, or SVG illustrations. It loads one checked-in PNG hero and one local stylesheet.

The Pages workflow publishes this directory as a static artifact. Successful deployment proves neither package installation nor live model behavior, field validation, regulatory approval, or operational authority.
